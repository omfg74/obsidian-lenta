# Лента

Плагин Obsidian. Пока заметка открыта в режиме редактирования, команда «Вставить новые» скачивает ещё не вставленные jpeg, png, gif и webp и кладёт их под текущий абзац. Свои снимки и блок «мне прислали» идут вместе, от старых к новым. «Выбрать фото» вставляет один кадр, в том числе повторно.

На iPad команда ставится на панель редактора. На компьютере она же в палитре и на боковой панели.

## Установка

Репозиторий для BRAT: `omfg74/obsidian-lenta`. Он публичный. `omfg74/saved-inbox` закрытый, из него плагин не ставится.

1. Настройки → сторонние плагины → выключить ограниченный режим.
2. Обзор → найти BRAT → установить и включить. Если BRAT уже стоит, этот шаг не нужен.
3. Палитра команд → «BRAT: Add a beta plugin for testing».
4. Вставить `omfg74/obsidian-lenta`.
5. Включить «Лента».
6. В настройках плагина указать адрес ленты, логин и пароль страницы и нажать «Проверить».

На iPad заметка должна быть открыта на редактирование. Панель редактора → карандаш → «Лента: Вставить новые».

Пароль лежит в `.obsidian/plugins/saved-inbox/data.json` внутри хранилища.

## Сборка

```sh
npm install
npm test
npx tsc --noEmit
npm run build
```

В папке должны лежать `manifest.json`, `main.js` и `styles.css`. Релиз на GitHub — эти три файла вложением к тегу `0.1.0`. BRAT берёт их из релиза.
